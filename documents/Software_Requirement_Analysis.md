Software Requirement Analysis
1. Introduction
Fleet Maintenance Scheduling Platform is a system developed to manage vehicles and their maintenance details. It helps fleet managers keep track of when a vehicle needs servicing.
2. Purpose
The main purpose of this project is to make vehicle maintenance easier to manage. It helps users avoid forgetting service dates and keeps all records in one place.
3. Scope
The system will store vehicle details and maintenance information. Users can schedule maintenance, update its status and check previous service records.
4. Existing System
In many places, vehicle maintenance details are maintained using notebooks or Excel sheets. It can be difficult to keep track of all vehicles and their service dates manually.
5. Proposed System
Our system provides one platform to manage all fleet maintenance activities. It helps users schedule services and easily check the maintenance history of vehicles.
6. Functional Requirements
The system should allow users to add and update vehicle details. It should also allow them to schedule maintenance, update service details and view maintenance history.
7. Non-Functional Requirements
The system should be easy to use and should respond properly to user requests. User information and maintenance records should also be stored securely.
8. User Roles
There are three main users in the system: Admin, Fleet Manager and Maintenance Staff. Each user will have access to features based on their role.
9. Hardware Requirements
A basic computer with 4 GB RAM and sufficient storage is enough to run the system. An internet connection is needed when using the online version.
10. Software Requirements
The project will be developed using Python, Django, React and MySQL. Git and GitHub will be used to manage the project files.
11. System Constraints
The system depends on the information entered by the users. Features like GPS tracking and IoT vehicle monitoring will not be included in the initial version.
12. Assumptions
Users are expected to enter the correct vehicle and maintenance details. Maintenance staff should update the service information after maintenance is completed.
13. Future Enhancements
In the future, GPS tracking and IoT features can be added to the system. AI-based predictive maintenance and a mobile application can also be added.
